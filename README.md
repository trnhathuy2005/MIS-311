# MIS 311
## Electric Vehicle Data Analysis
### 1. Data Overview
The Electric Vehicle dataset consists of 202 records and 6 variables: Vehicle Identification Number (VIN), City, Postal Code, Model Year, Make, and Model. The dataset provides information about electric vehicles and can be used to explore vehicle manufacturers, model years, and geographical distribution. This project uses Microsoft Excel to perform data cleaning, descriptive statistics, and data visualisation to identify meaningful business insights.
